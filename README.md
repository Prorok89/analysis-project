# Parser Combinator Log Parser

Беззависимая библиотека парсер-комбинаторов на Rust для разбора структурированных логов.

## Архитектура

Проект состоит из трёх частей:

- **parse.rs** -- примитивы парсер-комбинаторов и типы данных логов
- **lib.rs** -- чтение и фильтрация логов (`read_log()`)
- **main.rs** -- CLI-точка входа

## Внесённые исправления

### 1. Лишние вызовы `.clone()`

Заменены на ссылки. В `main.rs` вместо `args[1].clone()` используется `&args[1..].first().ok_or("...")?`. В трейте `Parser` параметр `input: String` заменён на `input: &'a str`, что убирает аллокации при каждом вызове парсера.

### 2. `Rc<RefCell<T>>` заменён на дженерики

Убраны обёртки `Rc<RefCell<T>>`, которые использовались для общего изменяемого состояния. Парсер-комбинаторы теперь напрямую владеют вложенными парсерами через обобщённые типовойые параметры.

### 3. Циклы заменены на итераторы

В `lib.rs` функция `read_log()` переписана с `for` + `.push()` на `.filter().collect()`. Ручной поиск по request ID заменён на `request_ids.contains(&log.request_id)`.

### 4. `unsafe` код удалён

Убран `transmute` и другие unsafe-операции. Весь парсинг теперь на безопасном Rust.

### 5. Сигнелтон удалён

Убран `LogLineParser` за `OnceLock`. Парсеры теперь создаются по требованию через трейт-фабрику `Parsable` (`T::parser()`).

### 6. Чрезмерная валидация заменена на tight-типы

Вместо ручной проверки «ноль?» после парсинга, `stdp::U32::Dest` возвращает `NonZeroU32`, `stdp::I32::Dest` -- `NonZeroI32`. Поля структур (`Backet::count`, `UserCash::count`, `CreateUser::authorized_capital`, `RegisterAsset::liquidity`, `LogLine::request_id`) используют `NonZeroU32` напрямую. Ноль отклоняется на этапе парсинга с `Err(())`.

### 7. Дублирование кода устранено

Создана обобщённая функция `just_parse<T: Parsable>()` вместо повторения логики «распарсить и вернуть» на разных местах.

### 8. Трейтовые объекты удалены

Убрана абстракция `MyReader`. Функция `read_log()` принимает `R: std::io::Read` напрямую, использует конкретный `LogIterator<R>`.

### 9. `if` вместо `match`

В `lib.rs` магические константы `READ_MODE_ALL`/`READ_MODE_ERRORS`/`READ_MODE_EXCHANGES` заменены на `enum ReadMode`, цепочка `if/else if/else` в `read_log()` переписана на `match mode { ... }`.


### 10. Большой вариант enum обёрнут в `Box`

Вариант `AppLogTraceKind::Connect(AuthData)` занимал 1024 байта на стеке. Заменён на `Connect(Box<AuthData>)`, массив вынесен в кучу. В `Map`-закрытии результат оборачивается `Box::new()`.

### 11. `main()` возвращает `Result` вместо паники

Изменено на `fn main() -> Result<(), Box<dyn std::error::Error>>`. Все `.unwrap()` заменены на `?` и `.map_err()`. Доступ к аргументам командной строки через `&args[1..].first().ok_or("использование: cli <file>")?`.
